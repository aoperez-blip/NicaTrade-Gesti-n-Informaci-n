# Gestión Digital de Información para NicaTrade International

## Nombre del proyecto

Gestión Digital de Información para NicaTrade International.

## Objetivo

Organizar información relacionada con una operación de importación desde México hacia Nicaragua utilizando diferentes herramientas digitales.

## Empresa

NicaTrade International.

## Operación analizada

Importación comercial de productos desde México hacia Nicaragua.

## Herramientas utilizadas

- Microsoft Word
- Microsoft Excel
- Microsoft PowerPoint
- Google Drive
- GitHub

## Productos del proyecto

El proyecto incluye diferentes documentos relacionados con el análisis de una operación de importación:

- Análisis de datos en Excel.
- Informe ejecutivo en Word.
- Presentación de resultados en PowerPoint.
- Gestión y almacenamiento de documentos mediante Google Drive.
- Almacenamiento y registro de cambios mediante GitHub.

## Resultados principales

La operación analizada comprende 50 productos y 6,675 unidades, con un valor total de $40,359.00 USD.

## Conclusión

El uso de herramientas digitales permite organizar, almacenar, analizar y compartir información de manera eficiente. GitHub permite mantener los archivos del proyecto en un repositorio y registrar los cambios realizados durante su desarrollo.
